# 🖥️ Cursor Website Clone

A pixel-perfect **frontend clone** of the [Cursor](https://cursor.com) AI code editor website, built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

![Cursor Clone Preview](images/cursor-wallpaper.png)

---

## ✨ Features

- **Responsive Design** — Fully responsive layout that adapts seamlessly from desktop to mobile screens
- **Interactive Navigation** — Hover-activated dropdown menus for *Product* and *Resources* sections
- **Mobile Hamburger Menu** — Smooth full-screen overlay navigation with animated sub-menu panels and back/close controls
- **Hero Section** — Eye-catching headline and call-to-action buttons matching the original Cursor landing page
- **Trusted By Section** — Showcase of partner/client logos in a clean grid layout
- **Try Cursor CTA** — Prominent download call-to-action section
- **Complete Footer** — Multi-column footer with Product, Resources, Company, Legal, and Connect sections
- **Modern Typography** — Uses [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) from Google Fonts
- **Dark Theme** — Sleek dark color scheme (`#14120b`) consistent with the original Cursor aesthetic

| Technology | Purpose |

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser — no build tools or package managers required.

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/hafiz-umair-786/Cursor_Clone.git
   ```
2. **Navigate into the project**
   ```bash
   cd Cursor_Clone
   ```
3. **Open in your browser**
   - Simply double-click `index.html`, **or**
   - Use a live server extension (e.g., VS Code's *Live Server*) for the best experience:
     ```bash
     # If you have the VS Code Live Server extension, right-click index.html → "Open with Live Server"
     ```
